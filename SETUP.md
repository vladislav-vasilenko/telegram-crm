# Первое подключение Telegram CRM

## Какие данные нужны

| Данные | Где создать | Куда вставить |
| --- | --- | --- |
| **API_ID** (число) | my.telegram.org → API development tools | Веб-панель → Подключить Telegram → API_ID |
| **API_HASH** (32 символа) | Там же, поле App api_hash | Веб-панель → Подключить Telegram → API_HASH |
| Номер телефона | Номер вашего аккаунта Telegram | Там же, в международном формате, например +79991234567 |
| Код входа | Приходит способом, выбранным Telegram: обычно служебный чат Telegram, иногда SMS | Следующий экран «Код входа» |
| Облачный пароль | Ваш существующий пароль двухэтапной проверки, если включён | Экран «Двухэтапная проверка» |
| **BotFather token** | @BotFather → /newbot | **В эту CRM не вставляется: он для отдельного бота** |

Для чтения личной истории нужен пользовательский MTProto-клиент. API_ID/API_HASH идентифицируют приложение; номер, код и пароль авторизуют ваш аккаунт. BotFather выдаёт другой тип доступа — к созданному боту, а не к вашему аккаунту. [Официальное описание авторизации Telethon](https://docs.telethon.dev/en/stable/basic/signing-in.html).

## 1. Создать API_ID и API_HASH

1. Откройте [my.telegram.org](https://my.telegram.org) в браузере.
2. Введите номер аккаунта Telegram с кодом страны.
3. Подтвердите вход кодом, который Telegram пришлёт для этой операции. Это отдельный вход на сайт.
4. Откройте **API development tools**.
5. Если приложение ещё не создавали, заполните **Create new application**:
   - App title: `Telegram CRM`.
   - Short name: `dialoguecrm` (латиница без пробелов; при необходимости другой уникальный вариант).
   - Platform: `Desktop`.
   - URL: можно оставить пустым.
   - Description: `Personal local chat organizer`.
6. Нажмите **Create application**.
7. Найдите **App api_id** и **App api_hash**. Оставьте страницу открытой для копирования. Если приложение уже есть, используйте выданные ранее данные.

Эти шаги соответствуют [официальной инструкции Telegram](https://core.telegram.org/api/obtaining_api_id). Интерфейс сайта может немного отличаться. API_HASH не публикуйте.

## 2. Вставить данные в CRM

1. Нажмите значок **Telegram CRM** в Dock. Откроется [локальная панель](http://127.0.0.1:4180).
2. Нажмите **Подключить Telegram** внизу слева, в пустой панели или на плашке демо. На узком экране используйте **Обновить чаты**.
3. Скопируйте число **App api_id** в поле **API_ID**.
4. Скопируйте **App api_hash** в поле **API_HASH**.
5. Введите номер вашего Telegram в формате `+79991234567`.
6. Нажмите **Получить код** и введите полученный код в панели CRM.
7. Если включена двухэтапная проверка, введите облачный пароль Telegram.
8. После подключения начнётся загрузка чатов. Личные чаты, группы, каналы и архив появятся в панели.

При истечении кода нажмите **Запросить заново**. При FloodWait дождитесь указанной паузы. Код входа и облачный пароль CRM не сохраняет. API_ID/API_HASH и сессия сохраняются локально, поэтому повторный вход обычно не нужен. Для отзыва сессии откройте Telegram → Настройки → Устройства и завершите сессию Dialogue CRM. Секретные чаты не доступны как обычная облачная история MTProto-клиента.

## Если код не приходит: вход по QR

В панели нажмите **Подключить Telegram → Войти по QR**. Если API_ID/API_HASH уже сохранены, вводить их повторно не нужно. При первом подключении заполните только API_ID/API_HASH, затем нажмите «Войти по QR»; номер телефона для этого способа не нужен.

На телефоне откройте **Telegram → Настройки → Устройства → Подключить устройство**, отсканируйте QR в панели CRM и подтвердите вход. QR обновляется автоматически по истечении срока. Если включена двухэтапная проверка, затем введите облачный пароль в CRM. Сканируйте через раздел «Устройства» внутри Telegram, а не обычной камерой.

Для входа по коду панель показывает способ, который вернул сервер Telegram: служебный чат на подключённых устройствах, SMS, email или звонок. Это ответ API о выбранной доставке, а не доказательство получения. При наличии следующего способа доступна «Повторить доставку», с соблюдением таймера Telegram. Принудительное SMS стороннему клиенту не гарантируется; не отправляйте запросы многократно подряд. Если Telegram требует неподдерживаемую форму входа, используйте QR.

После перезапуска сервера незавершённый вход по коду надо начать заново. Сохранённые API_ID/API_HASH остаются на месте. Подробности: [авторизация Telegram](https://core.telegram.org/api/auth), [официальный QR-вход](https://core.telegram.org/api/qr-login).

## 3. BotFather: как создать токен и почему он здесь не нужен

Если вам отдельно нужен Telegram-бот:

1. Откройте официального [@BotFather](https://t.me/BotFather).
2. Отправьте `/newbot`.
3. Введите отображаемое имя, например `My Chat Helper`.
4. Выберите уникальный username, заканчивающийся на `bot`, например `my_personal_chat_helper_bot`.
5. BotFather выдаст токен вида `123456789:AA...`.
6. Сохраните его в менеджере паролей; передавать его следует только приложению, которое работает с этим ботом.

**Токен нельзя вставлять вместо API_ID или API_HASH.** В этой версии CRM нет поля для BotFather-токена, потому что бот не получает ваши старые личные переписки. Создавать бота для текущей задачи необязательно. [Официальная инструкция BotFather](https://core.telegram.org/bots/features#botfather).

## 4. LLM: два способа

Без API: выделите чаты → **Копировать по 20 сообщений** → вставьте в свою LLM → скопируйте JSON → **Импорт ответа**. Этот вариант не требует ключей LLM в CRM.

Через API: создайте ключ в [OpenAI Platform](https://platform.openai.com/api-keys), откройте CRM → **Настройки → OpenAI API key**, вставьте ключ и выберите модель, доступную вашему API-аккаунту. Сохраните. Затем выделите чаты → **Анализ LLM → Отправить в OpenAI**. API оплачивается отдельно от подписки ChatGPT. Автоматический LLM-анализ остальных чатов после сканирования включается отдельной галочкой.

## 5. Dock и управление сервисом

Приложение установлено в `~/Applications/Telegram CRM.app`, исходники — в `/Users/vladmac/Documents/ChatGPT/telegram-crm`. Не перемещайте проект без переустановки ярлыка: приложение содержит абсолютный путь запуска.

Обычное закрытие браузера не останавливает сервер. Для остановки:

```bash
cd /Users/vladmac/Documents/ChatGPT/telegram-crm
.venv/bin/python scripts/service.py stop
```

После следующего нажатия на значок Dock сервер запустится снова. Автозапуск при входе в macOS не устанавливается.

Если изменили путь проекта, сначала пересоздайте `.venv` и установите зависимости, затем:

```bash
.venv/bin/python scripts/install_macos_app.py
```

Если порт 4180 занят, подробности запуска находятся в `.data/server.log`. Первый запуск может потребовать разрешить доступ macOS к папке Documents; предоставьте доступ именно этому локальному приложению, если macOS покажет такой запрос.
